# Herramientas del Proceso de Diseño

Sitio web interactivo en HTML5 que presenta las herramientas del proceso de diseño organizadas en 6 fases fundamentales. Cada herramienta incluye descripción, propósito principal y contexto de uso.

## Fases

1. **Investigación y Empatía** — Comprensión profunda de usuarios, sus necesidades y contexto.
2. **Definición** — Transformación de hallazgos en un enunciado claro del problema.
3. **Ideación y Conceptualización** — Generación creativa de soluciones potenciales.
4. **Evaluación de Alternativas** — Análisis y selección de las ideas más prometedoras.
5. **Diseño Detallado** — Especificaciones técnicas precisas para implementación.
6. **Validación y Verificación** — Confirmación de que la solución cumple requisitos y resuelve el problema.

## Tecnologías

- HTML5
- CSS3 (Flexbox, Grid, animaciones)
- JavaScript (Vanilla JS, sin frameworks)

## Estructura de archivos

```
index.html         Página principal
style.css          Estilos (fondo claro, paleta #9933cc / #3399ff)
app.js             Lógica del modal interactivo
datos.js           Datos estructurados de herramientas por fase
README.md          Este archivo
AGENTS.md          Contexto para asistentes IA
session-log.md     Bitácora de desarrollo
```

## Cómo usar

Abre `index.html` en cualquier navegador moderno. No requiere servidor ni dependencias.
